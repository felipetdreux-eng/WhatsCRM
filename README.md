# WhatsCRM

CRM leve para organizar prospecção comercial pelo WhatsApp.

## Recursos

- Cadastro de estabelecimento e telefone
- Status: Não respondido, Em andamento, Trabalhando, Vendido e Descartado
- Observações por lead
- Busca de contatos
- Atalho para abrir conversa no WhatsApp
- Contagem de leads e vendas
- Persistência local no navegador
- Interface responsiva

## Rodar localmente

```bash
npm install
npm run dev
```

## Próximos passos

A versão atual é um MVP local. Evoluções previstas incluem autenticação, banco de dados, histórico de interações, mensagens/modelos de abordagem e automações.
